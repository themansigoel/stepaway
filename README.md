## 🌟 Key Features
- **Meeting-Aware Engine**: Automatically pauses timer during Zoom, Meet, Teams, or Keynote presentations.
- **HUD Posture & Eye Guides**: Spine Align and 20-20-20 Rule Blink Guide overlays.
- **Strict Micro-Breaks**: Optional screen locking to enforce true restorative recovery.
- **100% Native macOS**: SwiftUI and AppKit with zero external telemetry.
